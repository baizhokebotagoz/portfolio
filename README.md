## Реализованные проекты

### [Анализ монетизации и экономики онлайн-игры](https://github.com/baizhokebotagoz/game-monetization-sql-adhoc-analysis)
**Стек:** SQL (PostgreSQL), CTE, Window & Aggregate Functions
**Описание:** Продуктовый и исследовательский анализ (EDA) данных ролевой онлайн-игры "Секреты Тёмнолесья". В ходе проекта:
* Рассчитана конверсия в платящих игроков и проанализировано влияние игровой расы на склонность к донату.
* Проведен анализ внутриигровой экономики: оценка распределения стоимости покупок и выявление аномальных транзакций.
* Выполнена ad-hoc сегментация активности пользователей для балансировки игровой механики.
* Сформулированы бизнес-рекомендации по персонализации маркетинга и развитию игрового магазина.

### [Аналитика рынка недвижимости: стратегия экспансии и оценка ликвидности](https://github.com/baizhokebotagoz/real-estate-sql-adhoc-datalens)

**Стек:** SQL (PostgreSQL), CTE, Window Functions, PERCENTILE_CONT/DISC, Yandex DataLens
**Описание:** Ad-hoc анализ объявлений сервиса недвижимости для формирования стратегии выхода компании на рынок Санкт-Петербурга и Ленинградской области. В ходе проекта:
* Очищены данные от аномалий с помощью расчетов перцентилей (1% и 99%) для площади, цен и физических параметров объектов.
* Проведена оценка ликвидности и времени экспозиции лотов: выведено различие между динамичным массовым рынком области (продажи за 1–3 месяца) и медленным высокомаржинальным рынком города (>6 месяцев).
* Исследованы сезонные паттерны: выявлены пики спроса и предложения (сентябрь–ноябрь) и временное отставание спроса от предложения на 1–2 месяца при реализации дорогого жилья.
* Профилированы локальные рынки Ленобласти: выделен ТОП-15 городов (60% предложения региона) и точки с максимальной конверсией сделок (>92%).
* Доработан и настроен интерактивный BI-дашборд в Yandex DataLens для отслеживания динамики рынка.
* Сформулированы продуктовые и маркетинговые рекомендации по формированию портфеля жилья и срокам старта рекламных кампаний.
