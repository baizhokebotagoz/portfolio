## Реализованные проекты

### [Анализ венчурного рынка и M&A сделок](https://github.com/baizhokebotagoz/startup-market-eda)
**Стек**: Python (Pandas, NumPy, Matplotlib, Seaborn), EDA, Статистический анализ, Data Preprocessing

**Описание**: Исследование факторов успешности стартапов и тенденций на рынке венчурных инвестиций для крупного инвестора. В ходе проекта:
* Проведена глубокая предобработка и нормализация данных, устранена проблема структурных пропусков и аномалий.
* Рассчитаны статистические границы выбросов (`funding_total`) и выявлен феномен «скрытого банкротства» — сделок по поглощению за $0/1 при наличии исторического финансирования.
* Выделены перспективные отраслевые кластеры с высокой стоимостью экзита и волатильностью (`Biotech`, `Cleantech`).
* Сформулированы стратегические рекомендации по минимизации рисков на ранних стадиях и выбору целевых ниш для инвестиций.

### [Аналитика рынка недвижимости: стратегия экспансии и оценка ликвидности](https://github.com/baizhokebotagoz/real-estate-sql-adhoc-datalens)

**Стек:** SQL (PostgreSQL), CTE, Window Functions, PERCENTILE_CONT/DISC, Yandex DataLens

**Описание:** Ad-hoc анализ объявлений сервиса недвижимости для формирования стратегии выхода компании на рынок Санкт-Петербурга и Ленинградской области. В ходе проекта:
* Очищены данные от аномалий с помощью перцентилей (1% и 99%), исследованы сезонные паттерны и пики спроса.
* Выявлено различие в ликвидности: быстрый массовый рынок области (продажи за 1–3 месяца) против медленного высокомаржинального рынка города (>6 месяцев).
* Профилированы локальные рынки Ленобласти (выделен ТОП-15 городов и зоны с конверсией сделок >92%).
* Настроен интерактивный BI-дашборд в Yandex DataLens для мониторинга динамики рынка и подготовки продуктовых рекомендаций.

### [Анализ монетизации и экономики онлайн-игры](https://github.com/baizhokebotagoz/game-monetization-sql-adhoc-analysis)
**Стек:** SQL (PostgreSQL), CTE, Window & Aggregate Functions

**Описание:** Продуктовый и исследовательский анализ (EDA) данных ролевой онлайн-игры "Секреты Тёмнолесья". В ходе проекта:
* Рассчитана конверсия в платящих игроков и проанализировано влияние игровой расы на склонность к донату.
* Проведен анализ внутриигровой экономики: оценка распределения стоимости покупок и выявление аномальных транзакций.
* Выполнена ad-hoc сегментация активности пользователей для балансировки игровой механики.
* Сформулированы бизнес-рекомендации по персонализации маркетинга и развитию игрового магазина.
